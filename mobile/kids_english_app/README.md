# Kids English app (Flutter)

Little Learners track (ages 3-5): letters A-Z. Parent area in Arabic (RTL, English optional) behind a parental gate;
child area in English with 64 dp+ touch targets. Works fully offline: lessons, audio and images are bundled in `assets/`
(produced by `tools/AssetGenerator`), profiles/progress/settings live in local storage. No AI, ads, analytics or cloud SDKs.

## First-time setup (platform folders are not committed yet)
The Dart code, tests and assets are here; the Android/iOS runner folders are generated by Flutter:
```
cd mobile/kids_english_app
flutter create . --platforms=android,ios --project-name kids_english_app --org com.dandoona
flutter pub get
flutter analyze
flutter test
flutter run
```
`flutter create .` keeps the existing `lib/`, `test/`, `pubspec.yaml` and `assets/`. Android: add the microphone permission
when the record-and-listen activity is built (Phase 3). Use a Flutter SDK with Dart >= 3.9.

## Structure (feature-first)
```
lib/core/        palette (mirrors content/style/palette.json), theme, strings (ar/en), storage, shared widgets
lib/features/
  content/       little_learners.json models + loader
  profiles/      child profiles (name, avatar, birth year) + validation + local storage
  progress/      progress records (mirror the API's ProgressRecord) + unlock rule
  settings/      language, session minutes (default 15), unlock-all, onboarding flag
  gate/          parental gate: press-and-hold, then a multiplication
  session/       session timer + time-up overlay (needs the gate to continue)
  parent/        onboarding, child form, dashboard, profiles, settings (Arabic)
  child/         profile picker, 26-letter map, lesson screen (English)
lib/router.dart  routes + guards (parent area unreachable without the gate)
test/            logic tests (incl. the real bundled JSON and asset files) and widget tests (gate, full flow, map, timer)
```

## Assets
`assets/` is written by `dotnet run --project tools/AssetGenerator -- export --track little-learners`, which also registers
every asset folder in `pubspec.yaml` (Flutter does not include sub-folders). Do not edit by hand; swap picks with the tool
(see `docs/asset-decisions.md`). Self-drawn `.svg` images are rendered with `flutter_svg` (MIT), generated `.webp` with `Image.asset`.
